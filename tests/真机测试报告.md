## 5. 真实环境实证结论（环境限制，非应用缺陷）
1. **VSPE 虚拟口**：getPorts 顺序在重启/刷新间不稳定（COM10 有时索引 0 有时 1）→ 测试驱动增加 COM10 校准（连接+发送回读确认）；端口名回退"串口 #N"（无 USB 信息，应用既定设计）
2. **VSPE stop/start 后连接栈不可靠**（停止仿真不产生读/写错误，OS 层实证写入静默成功/读取超时；恢复后有时拒绝连接）→ 错误路径中 open 失败用"端口不存在"实构；异常断开/写失败标记为注入式 E2E 覆盖（T17/T38）
3. **大数据后 VSPE Pair 会话损坏**（2MB 突发后流以 done 结束）→ 应用 v0.6 正确识别为断开（D8 修复）；空闲稳定性测试移到 burst 之前
4. **消费速率限制**（VSPE+headed 浏览器约 85KB/s）→ 2s flush 周期内无法积累 2MB，自动日志段满轮转（_001/_002）无法在真实链路触发 → 轮转逻辑由注入式 E2E T43 覆盖（209/209 含目录模式轮转断言）；真机验证 2.2MB 完整落盘无丢失
5. **同端口多客户端**：VSPE 允许共享打开但行为不稳定（有时挂起）→ 端口切换验证采用独占连接 + 对端回读
