# 执行计划库（Plans）

> 规则 1/11：每项工作必须先有计划；计划文件长期保存；每步执行后立即更新「实际执行结果」，保证可重现。

## 命名规范
`plans/T<任务编号>-<任务名>.md`

## 流程
1. 新任务 → 复制 `docs/计划模板.md` → 生成计划草稿
2. 交互闭环（规则 2）→ 事实核查（规则 10）→ 定稿
3. 逐步执行，每步更新实际执行结果（规则 11）
4. 完成后更新复盘与 Git 提交记录（规则 9/10）
