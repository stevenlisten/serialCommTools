## 1. 目标与验收标准（规则 3）

### 目标（一句话）
交付一个**单文件 HTML 串口侦听工具**：双击即可在 Chrome/Edge 中运行（file:// 协议），无后端、无构建、无外部依赖，实时侦听串口数据并支持日志留存；**界面美观，参考优秀设计**。

### 验收标准 —— 全部通过
- [x] AC-1 双击 serial-monitor.html 以 file:// 打开，navigator.serial 可用（Chrome 150 / Edge 150 实证）
- [x] AC-2 点击「连接」选择串口并成功打开（真实链路：VSPE COM10 验证通过）
- [x] AC-3 串口参数可配置：波特率（常用+自定义）、数据位、停止位、校验位、流控、编码
- [x] AC-4 接收数据实时显示：ASCII/HEX 可切换，时间戳可开关，自动滚动/暂停/清空可用
- [x] AC-5 搜索过滤可用（关键字匹配并高亮，大小写可切换，可仅显示匹配行）
- [x] AC-6 日志可一键导出为 .log 文件（含时间戳）
- [x] AC-7 配置写入 localStorage，刷新后保留
- [x] AC-8 断开（含异常断开）有状态提示，可一键重连
- [x] AC-9 虚拟串口对（VSPE COM10/COM11）+ Python 模拟数据源全功能自测通过
- [x] AC-10 单文件、离线可用、无 CDN、无构建依赖
- [x] AC-11 关键字报警（响铃 + 界面闪烁），有开关可开/关
- [x] AC-12 基础发送：HEX/ASCII 输入 + 快捷发送列表（可增删、持久化）
- [x] AC-13 UI 美观评审通过（暗色主题、清晰层级、状态可视化；截图见 records/T001-step6/）

### 范围边界
- 做：侦听接收为主 + 基础发送；所有功能自行完整实现
- 不做：后端服务、Electron/PWA 打包、多协议解析/波形仪表盘、固件升级、蓝牙/MQTT 等非串口通道
