## 虚拟串口对（VSPE，自测用）
- 端口对：**COM10 ↔ COM11**（Pair 设备，115200 默认即可互通）
- 创建方式：VSPE GUI → Create new device → Virtual Pair → COM10/COM11 → Start emulation（详见 methods/M005）
- 回环验证：Python pyserial COM10 写入 → COM11 读取一致 → PASS（2026-08-02）
- ⚠️ 评估版限制：启动时不自动加载配置；重启后若端口消失，按 M005 重新创建 Pair 即可（注册版可持久化）
