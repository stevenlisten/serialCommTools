# 工作协议（Work Agreement）

> 本文件是 serialCommTools 项目的**最高工作约定**。AI 与用户在每项工作中都必须遵守。
> 生效日期：2026-08-02 ｜ 位置：docs/工作协议.md ｜ 状态：✅ 已与用户确认

## 核心流程（一句话）
**计划 → 交互确认 → 目标明确 → 执行 → 自测/验证 → 对比评估 → 修订优化 → 持久化记录 → 方法沉淀 → Git 提交**，全程可追溯、可重现。

---

## 规则 1：工作一定要有计划
- 任何工作启动前，先按 `docs/计划模板.md` 生成执行计划，保存到 `plans/`。
- **无计划不执行**。计划未定稿前，AI 只做信息收集与事实核查，不做实施。

## 规则 2：计划一定要有交互
- AI 提交计划时，必须附「交互清单」：列出需要用户确认/补充的问题（技术栈、功能范围、验收标准、硬件环境等）。
- 用户补充后 AI 更新计划；交互清单全部闭环后计划才算定稿。
- 交互记录（问题/回答/状态）全部写入计划文件的「交互清单」章节，持久化。

## 规则 3：每项工作必须有明确目标
- 每项任务必须写明：目标（一句话）、可量化验收标准（3~8 条）、范围边界（做什么 / 不做什么）。
- 每个执行步骤也要有该步骤的小目标与预期结果。

## 规则 4：审查 → 自测 → 验证 → 对比评估 → 修订优化
每完成一步，必须按顺序执行并记录：
1. **审查（Review）**：自查产出的正确性、边界情况、安全隐患；
2. **自测（Self-Test）**：运行测试/样例，记录测试命令与结果；
3. **验证（Verify）**：用独立方法确认结果（实际运行、模拟数据、交叉检查）；
4. **对比评估（Compare）**：与目标/参考项目/上一轮结果对比，评估差距；
5. **修订优化（Revise）**：根据前四点结论修订优化，回到第 1 步复测，直到全部通过。

## 规则 5：过程必须持久化记录
- 所有关键过程写入 `records/`：时间戳、任务、步骤、操作命令、输入/输出、结果、问题、结论、证据（日志/截图路径）。
- 记录文件命名：`records/T<任务编号>-<步骤>-<序号>.md`，并纳入 Git 提交。

## 规则 6：成功方法沉淀（防重复造轮子）
- 每个步骤成功实施后，把可复用方法写入 `methods/`（格式见 `methods/README.md`）。
- 方法条目含：场景、方法步骤、命令/代码、验证方式、来源任务、日期。
- 新任务遇到相同场景先查方法库，**禁止重复发明轮子**。

## 规则 7：软件统一安装到 C:\tools\
- 所有执行过程中需要安装的软件/工具，一律安装到 `C:\tools\<工具名>\`，并完成环境配置。
- 每次安装必须登记到 `docs/环境与工具.md`：版本、路径、环境变量配置、验证命令。
- 优先便携版/绿色版；修改 PATH 等环境变量时，记录变更前后值。

## 规则 8：参考 GitHub 优秀项目
- 设计开发前，先查阅 `docs/参考项目.md`（已事实核查的仓库清单）。
- 借鉴前必须用 `git ls-remote` / 官方文档验证仓库存在性与版本（事实核查，规则 10）。
- 借鉴代码时遵守其许可证（MIT/Apache/GPL/LGPL 等），并在文档中注明来源。

## 规则 9：完成目标后提交 Git
- 每个里程碑完成后：工作记录 → Git 提交 → 推送 `https://github.com/stevenlisten/serialCommTools`（main 分支）。
- 提交信息规范：`类型(范围): 描述`，如 `docs(协议): 建立11条工作协议框架`。
- 凭据：token 已配置到 Windows 凭据管理器（git credential manager）。
- **安全红线：禁止将 token/密钥写入任何项目文件或提交到仓库。**

## 规则 10：反复复盘计划 + 事实核查
- 计划定稿前至少迭代 2 轮复盘；对每个关键事实（版本号、API、链接、命令）进行核查，并记录核查方式与结论。
- 执行中发现计划偏差，立即回更新计划，不得带偏差继续执行。

## 规则 11：计划即流程档案，逐步更新
- 每个计划文件长期保留在 `plans/`。
- **每执行完一步，立即更新该计划文件中对应步骤的「实际执行结果」**（做了什么、结果如何、证据记录在哪个文件）。
- 最终保证：任何人参照该计划文件即可完整重现流程。

---

## 偏离规则的处理
- AI 发现自身偏离规则 → 立即停止，按规则 4 闭环修正，并记录偏离原因。
- 用户发现 AI 偏离规则 → 直接指出，AI 立即修订并记录。
