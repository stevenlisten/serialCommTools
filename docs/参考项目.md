## 已核查可用的开源项目
| 项目 | 语言/框架 | 许可证 | 借鉴点 |
|------|-----------|--------|--------|
| [NanashiTheNameless/SerialTerminal](https://github.com/NanashiTheNameless/SerialTerminal) | 纯 Web（HTML/JS） | MIT | ⭐ 与本需求最接近：纯网页串口终端；Web Serial API 封装、读循环、UI 布局、离线单文件构建思路 |
| [googlechromelabs/serial-terminal](https://github.com/googlechromelabs/serial-terminal) | 纯 Web（HTML/JS） | Apache-2.0 | ⭐ Google 官方 Web Serial 终端 demo：规范写法与交互基线 |
| [Serial-Studio/Serial-Studio](https://github.com/Serial-Studio/Serial-Studio) | C++/Qt | 自定义（以仓库 LICENSE 为准） | 串口数据可视化仪表盘、帧解析/多协议框架、数据导出；本项目 UI 与解析架构的首选参考 |
| [serialport/node-serialport](https://github.com/serialport/node-serialport) | Node.js | MIT | JS/Electron 技术栈下的串口访问事实标准 |
| [pyserial/pyserial](https://github.com/pyserial/pyserial) | Python | 自定义（BSD 风格，以仓库 LICENSE 为准） | Python 串口访问事实标准，串口枚举/读写封装（自测数据源用） |
| [skiars/serialtool](https://github.com/skiars/serialtool) | C++/Qt | GPL-3.0 | 跨平台串口/网络调试工具：串口助手、终端、波形显示、文件传输；功能设计与 UI 参考 |
| [timzou/QtSwissArmyKnife](https://github.com/timzou/QtSwissArmyKnife) | C++/Qt | LGPL-3.0 | 多协议调试工具集（Serial/BLE/TCP/UDP/Modbus/CANBus）架构与插件化思路 |
| [svcghost/SerialWizard](https://github.com/svcghost/SerialWizard) | C++/Qt | 未声明（以仓库为准） | 简洁的跨平台串口调试工具，基础参数配置与收发交互设计 |
| [nkh-lab/pyterm](https://github.com/nkh-lab/pyterm) | Python | GPL-3.0 | 轻量 Python 串口终端，代码量小、易读，适合学习与快速原型 |
| [cortexm/ser2tcp](https://github.com/cortexm/ser2tcp) | Python | MIT | 串口↔TCP/Telnet/WebSocket 代理（基于 pyserial），网络化串口方案参考 |
| [sigrokproject/PulseView](https://github.com/sigrokproject/PulseView) | C++/Qt | GPL-3.0 | 协议解码/信号分析，若需求含串口协议解析与波形可视化可重点参考 |
