# Serial Listener · 串口侦听器

> 正式版本 v0.4 ｜ 发布日期：2026-08-02 ｜ 单文件 HTML 串口调试工具

## 这是什么

**Serial Listener 是一款纯本地运行的串口侦听/调试工具。** 整个软件只有一个 HTML 文件，
用 Chrome/Edge 浏览器直接双击打开即可使用——**无需安装、无需后端服务、无需构建、无需联网**。

它通过浏览器内置的 Web Serial 技术直接访问电脑上的串口（COM 口），
适用于：嵌入式开发调试、单片机/Arduino/ESP32 通信调试、串口设备数据侦听、协议分析、教学实验等场景。

## 技术特点

- **单文件交付**：全部功能打包在 1 个 HTML 文件（约 61KB），拷贝即用
- **无前后端架构**：无服务器、无数据库、无第三方依赖、无 CDN
- **数据仅存本机**：所有数据在本地处理，不上传任何内容；配置保存在浏览器本地
- **跨浏览器**：支持 Chrome / Edge 89+（含最新 150 版），file:// 双击即可运行

## 功能一览（v0.2 新增以 ★ 标注）

| 模块 | 功能 |
|------|------|
| 端口与连接 | 系统端口选择器授权、多端口切换、连接/断开/一键重连、异常断开提示 |
| 串口参数 | 波特率（常用 + 自定义）、数据位、停止位、校验位、流控、**编码（UTF-8 / GBK / Latin-1）** |
| 实时接收 | 文本 / HEX（hexdump + ASCII 列）双模式、时间戳开关、自动滚动、暂停缓存、一键清空 |
| ★ 编码健壮性 | **自动剥离 UTF-8 BOM（含跨块/流中重复）；跨重连保留多字节解码状态（不再偶发乱码）** |
| ★ 收发区分 | **发送数据实时显示在日志区（蓝绿色块 + → 箭头），与接收数据（默认色块）一目了然** |
| 过滤搜索 | 关键字高亮、大小写切换、仅显示匹配行（含 TX 行） |
| 关键字报警 | 接收数据匹配时响铃 + 界面闪烁 + 标题提醒（发送不触发），开关可控、多关键字 |
| 发送 | 文本 / HEX 输入、CR/LF 行尾、快捷发送列表（增删持久化）、命令历史（↑/↓）、Ctrl+C/D 控制字符 |
| ★ 自动日志 | **连接成功后自动保存日志到本地：可选保存目录（或浏览器下载目录）、开关可控、文件名=串口名+时间戳、每段 2MB 自动轮转防卡死、每条记录独立一行** |
| 日志导出 | 一键导出 .log（含时间戳与会话信息），文本/HEX 内容自适应，TX 行带 → 标记 |
| 状态监控 | RX/TX 字节计数、实时速率、连接状态与参数显示 |
| 其他 | 配置自动持久化（localStorage）、暗色现代界面、键盘快捷键、ARIA 无障碍标签 |

## 质量保障

- 注入式自动化测试：**44 组 / 205 项断言全部通过**（覆盖功能、业务合理性、边界、越界、
  极端数据、耦合关联、错误路径、安全注入、TX 显示、自动日志）
- 真实串口链路测试：**16 项断言全部通过**（VSPE 虚拟串口对 + 模拟设备收发双向验证）
- 支持中文（含 GBK 编码）、特殊字节、大数据流（实测 2MB 突发流畅）

## 隐私与安全

- 纯本地运行：接收到的数据**不会**离开您的电脑
- 自动日志保存在您指定的目录（或浏览器下载目录），由您自行管理
- 数据渲染全部经转义处理，可安全显示任意文本（含 HTML/脚本内容）
- 串口访问需浏览器授权（系统弹窗），符合浏览器安全模型
