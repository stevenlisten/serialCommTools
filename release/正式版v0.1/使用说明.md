# Serial Listener · 使用说明（正式版 v0.1）

## 一、运行环境

| 项目 | 要求 |
|------|------|
| 操作系统 | Windows 10 / 11（macOS/Linux 亦可，浏览器一致即可） |
| 浏览器 | **Chrome 或 Edge**（89 及以上版本；Firefox 151+ 亦可） |
| 网络 | 不需要（离线可用） |
| 串口 | 电脑上可见的 COM 口（USB 转串口、板载串口、蓝牙串口等） |

> 提示：如果双击打开后顶部出现红色提示条“当前浏览器不支持 Web Serial API”，
> 请改用 Chrome 或 Edge 打开本文件。

## 二、快速开始（4 步）

1. 用 **Chrome 或 Edge** 打开 `serial-monitor.html`（直接双击即可）
2. 点击右上角蓝色 **「连接」** 按钮
3. 在弹出的系统对话框中选择您的串口（如 COM3 / COM10），点击连接/确定
4. 状态栏显示 **「已连接」**，设备发来的数据即实时显示在接收区

## 三、界面布局

```
┌─ 顶栏：软件名 ｜ 端口 ｜ 波特率 ｜ 数据位 ｜ 停止位 ｜ 校验 ｜ 流控 ｜ 编码 ｜ [连接] ┐
├─ 工具栏：文本/HEX ｜ 时间戳 ｜ 自动滚动 ｜ 暂停 ｜ 清空 ｜ 搜索过滤 ｜ 报警 ｜ 导出日志 ┤
├─ 接收区：串口数据实时显示（支持超大流量）                                    │
├─ 发送区：HEX/文本输入 ｜ CR/LF ｜ 快捷发送 ｜ [发送]                           │
└─ 状态栏：连接状态 ｜ RX 计数 ｜ 速率 ｜ TX 计数 ｜ 参数 ｜ 时间 ┘
```

## 四、串口参数说明

| 参数 | 说明 |
|------|------|
| 波特率 | 常用列表（300~2000000）+ 自定义（选择“自定义…”后输入任意数值） |
| 数据位 | 8 或 7 |
| 停止位 | 1 或 2 |
| 校验位 | 无 / 偶校验 / 奇校验 |
| 流控 | 无 / 硬件 RTS/CTS |
| 编码 | **UTF-8**（默认）/ **GBK**（中文设备常用）/ **Latin-1**（逐字节） |

> 连接状态下修改参数会自动重新打开端口（热更新），历史数据保留、计数持续。

## 五、功能操作

### 接收显示
- **文本 / HEX 切换**：HEX 模式按 16 字节一行显示十六进制 + ASCII 列，便于分析二进制协议
- **时间戳**：每行前显示 [时:分:秒.毫秒]，可开关
- **自动滚动**：新数据自动滚到底部；关闭后可自由回看
- **暂停**：暂停显示但后台继续缓存（横幅显示缓存行数/字节），点击横幅或取消勾选即恢复
- **清空**：清空视图、日志、计数（相当于重新开始一次会话）

### 过滤 / 搜索
- 在搜索框输入关键字，匹配内容**黄色高亮**（对已有数据立即生效）
- `Aa` 按钮：切换大小写敏感
- `仅匹配` 按钮：只显示包含关键字的行

### 报警
1. 打开 **报警** 开关
2. 在输入框填写关键字，多个用逗号分隔（如 `error,温度过高`）
3. 收到包含任一关键字的数据时：**响铃 + 界面红色闪烁 + 标题栏提醒**

### 发送
- **文本模式**：输入内容后按 Enter 或点「发送」；可附加 CR / LF / CRLF 行尾
- **HEX 模式**：输入十六进制（如 `48 65 6C 6C 6F`，空格/逗号均可，大小写不限）
- **快捷发送**：点「+ 存为快捷」保存当前输入；点快捷项即发送；点 × 删除（最多 12 条，自动保存）
- **命令历史**：按 ↑/↓ 翻看历史发送内容（自动保存最近 50 条）

### 快捷键
| 按键 | 功能 |
|------|------|
| Enter（发送框） | 发送 |
| Ctrl + L | 清空 |
| Ctrl + C（发送框内） | 发送控制字符 0x03（SIGINT） |
| Ctrl + D（发送框内） | 发送控制字符 0x04（EOF） |
| ↑ / ↓（发送框内） | 命令历史 |

### 导出日志
- 点击 **「导出日志」**：生成 `serial_log_日期_时间.log` 文件（含时间戳、端口、参数等头部信息）
- 导出内容为**当前会话全量数据**（不受过滤影响），文本/HEX 条目按原始格式导出
- 文件保存在浏览器默认下载目录

## 六、常见问题（FAQ）

| 问题 | 解决 |
|------|------|
| 顶部红条提示不支持 Web Serial | 请使用 Chrome 或 Edge 打开（Firefox 需 151+） |
| 端口下拉为空 | 首次使用必须先点「连接」在系统弹窗中授权一次；授权后刷新页面即出现在列表 |
| 连接按钮点了没反应 | 确认系统弹窗被浏览器拦截/未点确认；或先点击「选择…」 |
| 中文显示乱码 | 将「编码」切换为 **GBK**（多数国产设备/模块为 GBK 编码） |
| 数据都挤在一行不换行 | v0.1 已支持 CR/LF/CRLF 三种换行；若仍不换行说明设备未发送换行符 |
| 报警不响铃 | 检查：报警开关已打开、关键字正确、系统/浏览器音量正常（首次触发需先与页面交互一次） |
| 看不到 COM 端口号（显示 USB#xxxx:yyyy） | 浏览器安全模型不暴露端口名，属正常现象；USB 设备显示厂商 ID |
| 日志导出到哪里了 | 浏览器默认下载目录（Chrome 设置 → 下载内容可查看） |
| 配置会丢吗 | 配置保存在浏览器 localStorage，同一浏览器/文件路径下刷新不丢；清理浏览器数据会清除 |

## 七、数据与隐私

- 本工具**纯本地运行**，串口数据不会上传到任何服务器
- 关闭页面即停止侦听；导出日志文件由您自行保管
- 如需长期记录，建议定期点击「导出日志」保存
