# 记录：T001-012 自动日志换行修复 v0.4

- 时间：2026-08-02
- 现象（用户反馈）：自动日志全部内容首尾相连，无法阅读（例：`[09:05:35.948]  [09:05:35.949]  StatrGetDetectResult[09:05:52.253]...`）
- 根因：AutoLog._line() 未在条目末尾追加换行符；flush() 用 join('') 直接拼接 -> 所有条目连成一行（导出日志用 join('\r\n')，故无此问题）
- 修复：_line() 每条追加 '\r\n'（目录模式与下载模式同时生效）
- 测试：T43 新增 2 项断言（目录/下载模式按行分隔、无粘连）；E2E 205/205、真实链路 16/16
- 版本：v0.4.0
- 发布：release/正式版v0.4/ + zip + tag v0.4
- 证据：serial-monitor.html、tools/e2e_test.cjs、tests/测试报告.md 第 10 节
