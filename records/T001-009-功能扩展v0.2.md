# 记录：T001-009 功能扩展 v0.2（TX 显示 + 自动日志保存）

- 时间：2026-08-02
- 需求：
  1. 发送数据显示在日志区，收发数据用不同色块区分
  2. 连接成功后自动保存日志到本地：可选存储位置（否则浏览器下载目录）、开关可控、文件名=串口名+时间戳、超过一定大小自动截断
- 实现：
  - TX 显示：viewAddTx() 蓝绿色块 + → 箭头；文本/HEX 双模式；进入日志（kind=tx）与导出（带 →）；Ctrl+C/D 显示 ^C/^D；不触发报警、不计 RX
  - 自动日志：AutoLog 模块（开关持久化、showDirectoryPicker 选目录、失败回退下载目录按段下载、文件名 端口_YYYYMMDD_HHMMSS.log、每段 2MB 轮转 _001/_002、每 2 秒落盘、连接开始/断开收尾、状态指示）
- 测试：新增 T42（8 断言）、T43（13 断言）；E2E 198/198、真实链路 16/16
- 发现并修复的缺陷：
  - D4 [中] 自动日志轮转空窗期 flush 清空缓存丢数据 -> writer 未就绪保留缓存重试
  - D5 [UI] 工具栏新增控件后搜索区子按钮与报警区重叠 -> 搜索区 min-width 300px + 工具栏换行间距
- 测试用例修正：T42 末尾未恢复发送模式（HEX）污染 T43 -> 补复位
- 发布：release/正式版v0.2/ + zip + tag v0.2
- 证据：serial-monitor.html、tools/e2e_test.cjs、tests/测试报告.md 第 8 节
