# 记录：T001-013 并发发送修复 v0.5（writer 锁冲突）

- 时间：2026-08-02
- 现象（用户反馈）：发送大数量或快速大数据推送时报 `Failed to execute 'getWriter' on 'WritableStream': Cannot create writer when WritableStream is locked`
- 根因：Serial.send() 每次调用都 getWriter()+releaseLock()；当上一次 write 尚未完成（大块数据背压、快速连续发送）时，流仍被锁定，再次 getWriter() 抛错
- 修复（Web Serial 推荐模式）：
  1. connect() open 成功后获取并持有单一 writer（state.writer）
  2. send() 直接 writer.write()，多次写入由 WritableStream 内部排队，无锁冲突
  3. disconnect()/onDisconnected() 先 releaseLock 再关闭端口
- 测试：新增 T45（TC-715~717，4 断言）：50 次同步并发点击、180KB+紧跟发送、无锁定错误、重连后发送；E2E 209/209、真实链路 16/16
